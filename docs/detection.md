# 検出処理と調整

- 320×240 RGB565 を40×30の平均輝度画像に縮小し、最大約30Hzで処理（取得間隔33ms）。
- 5×5画素の小領域を前の画像の周辺±6画素で探索する、疎なブロックマッチング型オプティカルフロー。
- 小領域ごとの平均輝度差を除いて照合し、照明変化の影響を抑制。
- 模様の少ない領域、不確かな照合、方向が揃わない移動を除外。
- 通常は横方向の移動を3回以上、80ms以上にわたり検出し、累積移動量が8画素相当以上で1イベント。
- 強い移動が同じ方向に連続する高速動作は、追加条件付きで2フレームから確定（下記参照）。
- イベント後は最低700ms、かつ動きが350ms落ち着くまで再入力を抑制。

### 調整する場所

`include/gesture_config.h` の定数を変更して再ビルドします。初期値は実機確認時の値です。

| 調整したいこと | 主な定数（名前空間） | 現在値 |
| --- | --- | --- |
| 必要な累積移動量 | `MinTravel` (`Detection`) | 8画素相当 |
| 遅い動きを除外する速度 | `MinSpeedPixelsPerSecond` (`Detection`) | 10画素相当/秒 |
| 設置位置に合わせた判定軸の傾き | `AxisTiltDegrees` (`Detection`) | -10°（選択した軸から直交軸への角度） |
| 斜め移動の除外 | `AxisDominance` / `MaxCrossTravelRatio` (`Detection`) | 各フレームで主軸が直交軸の1.5倍以上、累積直交移動は主軸の50%未満 |
| 横方向の票の割合 | `MinDirectionCoveragePercent` (`Flow`) | 主方向の票が全移動領域の50%以上 |
| 再入力までの待機 | `CooldownMs` / `QuietMs` (`Detection`) | 700ms / 350ms |
| フレーム間の探索範囲 | `SearchRadius` (`Flow`) | ±6画素 |
| 画像取得間隔 | `CaptureIntervalMs` (`Runtime`) | 33ms |
| 設置方向と左右反転 | `VerticalAxis` / `Mirror` (`Runtime`) | true / true |

距離・速度は縮小後の画像座標が基準で、縦軸を使う場合は縦横比で換算しています。
その後、`AxisTiltDegrees` に沿う成分と直交成分へ投影して判定します。
これは現在の設置で観測した手の軌跡への補正で、液晶の回転設定とは独立です。
画像サイズは320×240を割り切れる値に限ります。小領域の大きさを変更すると照合コストも
変わるため、`Flow` の模様・誤差のしきい値は併せて調整が必要です。
探索範囲や小領域の密度を増やす場合は、実機の `flow_ms` も確認してください。

高速動作用の調整では `Flow::SearchRadius` を5から6へ拡大し、`PatchStep` を3から2にして
照合位置を増やしました。通常の3フレーム・80ms・累積8画素相当の条件に加えて、
次の条件を満たす速い動きは2フレームから確定できます。

- 連続する有効フレームで、同じ向きにそれぞれ4画素相当以上移動する。
- 各フレームに方向の揃う小領域が4個以上ある。
- フレーム間隔は100ms以下、最初の有効フレームから25ms以上、累積移動量は10画素相当以上。
- 斜め移動・逆方向への戻りの除外と、イベント後の連発防止は通常と共通。

途中の静止・不確かなフロー・向きの反転で高速判定用の蓄積をリセットします。
`Detection` の `Fast` で始まる定数が高速判定の調整箇所です。
異なる速さの動きが混ざり、中央値付近に十分な支持がない場合は、同じ向きの速い小領域群も
候補にします。この補助判定では最低5領域かつ軸方向の票の1/3以上を必要とし、
方向の優勢条件は維持します。中央値に十分な支持がある場合はそちらを使います。
`Flow` の `FastCluster` で始まる定数で調整できます。
直近の高速動作の保存画像（`gesture-fast-02.jsonl`〜`gesture-fast-04.jsonl`）と
ゆっくりした動作（`gesture-slow.jsonl`）は、再生で右・左を各1回検出します。
`gesture-fast-01.jsonl` は引き続き左を取りこぼすため、設置や写り方による限界は残ります。
50msごとに6画素移動する合成画像を両軸・両方向で検証し、単発・逆向きの揺れ・途中の停止・
フレーム遅延の除外と、戻し動作の連発防止も確認しています。既存テストもASan/UBSan付きで通過しました。

手そのものを識別する学習モデルではないので、手以外の物体にも反応します。
カメラを動かした場合や、複数の物体が動く場合には誤反応する可能性があります。
近すぎる手、真っ暗な画像、画面を0.1秒程度で通過する動きは検出できないことがあります。

過去の確認結果は[調整記録](tuning-notes.md)を参照してください。画像データはリポジトリに含みません。
